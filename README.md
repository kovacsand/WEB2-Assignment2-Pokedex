# Pokémon Pokédex 
## A JavaScript Pokédex using the PokeAPI

[Live version](https://kovacsand.github.io/WEB2-Assignment2-Pokedex/) deployed through GitHub Pages

This was developed in early 2023 as part of the WEB2 (Web Development 2) course at VIA University College.

Feature highlights
- Asynchronous data fetching from the PokeAPI
- Displays Pokémon list, pagination
- Responsive and dynamic UI built with HTML, CSS & vanilla JavaScript
